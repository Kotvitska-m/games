Правила игры «Фильтр»

На экране появляется фраза, в которой каждое слово можно нажать. При нажатии слово становится полупрозрачным (неактивным) — повторное нажатие возвращает его активность.

Ваша задача — оставить активными только нужные слова (для каждой фразы их 3, иногда главное слово состоит из двух частей, тогда активных слов больше). Все остальные слова нужно «отфильтровать», сделав их неактивными.

Когда готовы — нажмите «Проверить». Правильно оставленные/отфильтрованные слова подсветятся зелёным, ошибки — красным.

Баллы: за каждое правильно оставленное активным ключевое слово — 3 балла. Если при этом вы не делали по нему «исправлений» (не нажимали на него туда-обратно) — ещё +1 балл.
